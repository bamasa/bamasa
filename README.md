**[trading-research-pipeline](https://github.com/bamasa/trading-research-pipeline)**
— a leakage-aware research pipeline for systematic trading. Honest costs, purged
and embargoed validation, and a register of every candidate with the condition
written down *before* the test that would refute it. Most of what it found is
negative; the one conditional edge is documented together with the market state
it needs and the three attempts to escape that state.
